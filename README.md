# babe
Babe, the Blue(tooth) Ox(imeter)

There is a "Beyond Oximeter" app that seems to power many of the Bluetooth fingertip oximeters. It wants you to sign up for an account before it will let you record data, despite showing you the data without having to do that. I'd prefer to keep my medical data to myself, thanks.

This is intended to be a replacement for "Beyond Oximeter" (and other similar sketchy proprietary apps).

Intended target devices:

* Innovo iP900BP-B
* Zacurate 500E-B
* Wellue KS-60FW
* iHealth PO3
